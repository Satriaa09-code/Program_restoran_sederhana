Aplikasi sederhana ini bertujuan untuk memenuhi tugas matakuliah.


program aplikasi sederhana ini berisi daftar menu, input pembelian menu maksimal 4, jumlah pembelian, 
promo buy 1 get 1 untuk kategori minuman setiap pembelian > 50k, promo diskon 10% setiap pembelian > 100k.
Ada input uang yang dibayar pembeli serta ada detail nota pemesanannya. Bukan hanya itu, ada biaya pajak dan layanan juga.


program aplikasi ini tidak memiliki validasi kuat, yang artinya masih validasi dasar.
